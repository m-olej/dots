# 🚀 ZELLIJ ESSENTIALS CHEATSHEET

## 🔓 THE GOLDEN RULE (LOCKED MODE)
- `<C-g>`            : Toggle Locked Mode (Unlocks Zellij / Returns to Neovim)
- `<Esc>`            : Return to Normal mode from other modes

## 🪟 PANE MANAGEMENT (Hit `<C-p>` first)
- `n`                : Open a new pane
- `x`                : Close the focused pane
- `<Arrows>`         : Navigate focus between panes

## 🗂️ TAB MANAGEMENT (Hit `<C-t>` first)
- `<C-t>`            : Enter Tab mode to add, move, or close tabs

## 📏 RESIZING & MOVING PANES
- `<C-n>`            : Enter Resize mode
- `+ / -`            : Increase or decrease pane size
- `<C-h>`            : Enter Move mode to relocate panes

## 📦 SESSION & NAVIGATION (Hit `<C-o>` first)
- `c`                : Open the Configuration screen
- `p`                : Open the Plugin manager
- `d`                : Detach from current session, leaving it running
- `w`                : Rename current session live

## 🖱️ SCROLLING (Hit `<C-s>` first)
- `<C-s>`            : Enter Scroll mode to scroll within the focused pane

## ⚡ QUICK ALT SHORTCUTS (Works when Unlocked)
- `<Alt-n>`          : Open a new pane instantly
- `<Alt-f>`          : Create a floating terminal above all other panes
- `<Alt-Arrows>`     : Change pane focus
- `<Alt-h/j/k/l>`    : Change pane focus
- `<Alt-i> / <Alt-o>`: Move the active tab to the left or right

# How to exit zellij

- `<C-q>`
